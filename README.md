# Adzen

Android 广告过滤、自动跳过与原生 View 屏蔽工具（LSPosed 模块）。

## 功能

- **八戒**：无障碍自动跳过、应用白名单、规则订阅与本地规则、统计与日志。
- **沙僧**：本地代理过滤、应用范围、域名规则与拦截统计。
- **悟空**：基于 LSPosed 的原生 View 屏蔽，以及独立 ROOT 守护与 hosts 替换入口。
- **设置**：WebDAV 云备份、后台保活、设备管理器入口及通用设置。
- 系统验证码通道通过系统通知 Hook 与系统进程剪贴板复制；通知监听提供额外通道。

## 权限与使用

- 自动跳过需开启无障碍服务；1 像素 view 保活需允许显示悬浮窗。
- Xposed 功能需在 LSPosed 中启用模块并选择目标应用。
- 系统验证码通道还需选择系统框架 `android`，更新后重启手机加载系统 Hook。
- 设备管理器通过系统界面手动授权。
